# Лабораторная работа №1

## Структура файлов данных

В каталоге `Task01` находятся исходные файлы набора данных и файлы, созданные в ходе выполнения лабораторной работы.

### Исходные файлы

- `genres.txt` — список жанров фильмов. Каждый жанр записан отдельной строкой.
- `occupation.txt` — список профессий пользователей. Каждая профессия записана отдельной строкой.
- `users.txt` — сведения о пользователях. Поля разделены символом `|`:
  1. `userId` — идентификатор пользователя;
  2. имя пользователя;
  3. адрес электронной почты;
  4. пол;
  5. дата;
  6. профессия.
- `movies.csv` — сведения о фильмах в формате CSV. Поля:
  1. `movieId` — идентификатор фильма;
  2. `title` — название фильма;
  3. `genres` — жанры фильма, разделённые символом `|`.
- `ratings.csv` — оценки пользователей фильмам в формате CSV. Поля:
  1. `userId` — идентификатор пользователя;
  2. `movieId` — идентификатор фильма;
  3. `rating` — оценка фильма;
  4. `timestamp` — временная метка.
- `tags.csv` — пользовательские теги для фильмов в формате CSV. Поля:
  1. `userId` — идентификатор пользователя;
  2. `movieId` — идентификатор фильма;
  3. `tag` — текст тега;
  4. `timestamp` — временная метка.

### Файлы, созданные в ходе лабораторной работы

- `ratings_count.txt` — содержит идентификаторы пользователя с минимальным и максимальным значением `userId` и количество записей для каждого из них.
- `sqlite.txt` — содержит информацию об установленной версии SQLite и доступных режимах вывода данных консольного клиента `sqlite3`.
