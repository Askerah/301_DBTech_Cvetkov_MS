# Task02 - ETL для базы данных фильмов

## Требования

Для работы необходимы:

- Python 3
- SQLite3
- Git Bash или другая Bash-совместимая оболочка

## Запуск

Перейти в папку Task02 и выполнить:

    ./db_init.bat

Скрипт запускает make_db_init.py, генерирует db_init.sql и создаёт базу movies_rating.db.

## Структура базы данных

Создаются таблицы:

- movies
- ratings
- tags
- users

## Результат

База содержит:

- movies - 9742 записи
- ratings - 18773 записи
- tags - 3683 записи
- users - 943 записи

Время генерации SQL и загрузки данных - около 1.14 секунды.
